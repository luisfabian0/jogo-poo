# 🗡️ Arena de Combate (Java)

Este projeto é um jogo de batalha em turnos desenvolvido em Java, onde combatentes de duas equipes (Aliança da Luz e Horda das Sombras) lutam até que uma equipe seja totalmente derrotada.

O jogo é executado via terminal e permite criar personagens de diferentes classes (Tanque, Mago e Atirador) e simular rodadas de combate.

## 📋 Pré-requisitos

Antes de começar, você precisa ter instalado:

- Java JDK 11 ou superior
- Git
- Um terminal (Prompt de Comando, PowerShell, Bash ou similar)

 Clone o repositório com:
 `git clone https://github.com/luisfabian0/jogo-poo.git`

 Entre na pasta do projeto:
 `cd jogo-poo` 

Compile o arquivo principal (Main.java):

`javac Main.java`


Ou compile todos os arquivos:

`javac *.java`

Após compilar, execute com:

`java Main`
